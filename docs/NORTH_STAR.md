# North Star

## 產品承諾

AI Lab OS 的承諾不是「有很多 AI 員工」，而是：

> 你用自然語言說明目標，系統結合你的長期背景與當前情境理解真正需求，選擇能力完成任務，自己驗證和修復，最後只把可信結果交給你。

核心感受應該是：

> **越使用越懂我，而且越來越多事情不用我自己管。**

## 使用者體驗

使用者只看到一個入口和一條工作進度：

```text
理解 → 計劃 → 執行 → 驗證 → 完成
```

內部可以有多個模型、工作器和 Skill，但使用者不需要選擇「哪個 Agent」。

## 四個必須同時成立的結果

1. **理解正確**：找出真正目標、對象、偏好、限制、成功標準和歧義。
2. **操作減少**：不再要求使用者在 ChatGPT、PowerShell、Cline 與瀏覽器之間搬運資訊。
3. **完成可信**：不以模型自述為完成，而以測試、狀態、輸出文件或回執證明。
4. **越用越好**：糾正會改善個人模型、上下文選擇和工作流程，而不是只增加聊天記錄。

## 北極星指標

優先觀察以下指標，而不是代碼量：

- Intent acceptance rate：使用者是否接受系統對需求的理解；
- Critical constraint recall：關鍵限制是否完整保留；
- Unnecessary clarification rate：不必要提問的比例；
- User correction rate：使用者需要說「不是這樣」的比例；
- Autonomous completion rate：無人工搬運完成的任務比例；
- Verified success rate：有證據的成功比例；
- Human interventions per run：每次任務需要多少次人工操作；
- Memory precision：被取出的記憶有多少真正相關且仍然有效。

## 非目標

第一階段明確不做：

- 100 個 Skill；
- 虛擬辦公室或員工房間；
- 無限制自我修改代碼；
- 把所有服務拆成微服務；
- 只靠向量搜索假裝長期記憶；
- 用版本號堆疊掩蓋沒有產品閉環。
